## Orden de lectura sugerido

**Para evaluar el producto (stakeholder, sponsor)**:
1. `manual-negocio.md` (qué problema resuelve, valor)
2. `comparacion-modelo.md` (qué cambió)
3. `manual-usuario.md` (cómo se opera)

**Para evaluar técnicamente (PM, tech lead)**:
1. `comparacion-modelo.md` (cambios feature-por-feature)
2. `/docs/specs/15-routing-roadmap.md` (decisiones técnicas)
3. `manual-usuario.md` (UX final)

**Para usar el sistema (operador, gerente)**:
1. `manual-usuario.md` (solo lo de tu rol)

**Para correr la demo**:
1. `/DEMO.md` (setup + guion completo)
